\section*{Función de transferencia del sistema de tres masas}

Definimos:

\[
a_1=m_1s^2+(b_1+b_2)s+k_1+k_2
\]

\[
a_2=b_2s+k_2
\]

\[
a_3=m_2s^2+(b_2+b_3)s+k_2+k_3
\]

\[
a_4=b_3s+k_3
\]

\[
a_5=m_3s^2+(b_3+b_4)s+k_3+k_4
\]

Las ecuaciones en Laplace son:

\[
Y_1a_1=Y_2a_2
\]

\[
Y_2a_3=Y_1a_2+Y_3a_4
\]

\[
Y_3a_5=Y_2a_4+F(s)
\]

\subsection*{Paso 1. Despejar $Y_1$}

De la primera ecuación:

\[
Y_1=\frac{a_2}{a_1}Y_2
\]

\subsection*{Paso 2. Sustituir en la ecuación de $m_2$}

Sustituyendo en

\[
Y_2a_3=Y_1a_2+Y_3a_4
\]

se obtiene

\[
Y_2a_3=
\left(
\frac{a_2}{a_1}Y_2
\right)a_2
+
Y_3a_4
\]

\[
Y_2a_3=
\frac{a_2^2}{a_1}Y_2
+
Y_3a_4
\]

Pasando términos:

\[
Y_2a_3-
\frac{a_2^2}{a_1}Y_2
=
Y_3a_4
\]

Factorizando:

\[
Y_2
\left(
a_3-\frac{a_2^2}{a_1}
\right)
=
Y_3a_4
\]

Despejando \(Y_2\):

\[
Y_2=
\frac{a_4Y_3}
{
a_3-\frac{a_2^2}{a_1}
}
\]

Multiplicando numerador y denominador por \(a_1\):

\[
Y_2=
\frac{a_1a_4Y_3}
{
a_1a_3-a_2^2
}
\]

\subsection*{Paso 3. Sustituir en la ecuación de $m_3$}

Partimos de:

\[
Y_3a_5=Y_2a_4+F(s)
\]

Sustituyendo \(Y_2\):

\[
Y_3a_5=
a_4
\left(
\frac{a_1a_4Y_3}
     {a_1a_3-a_2^2}
\right)
+F(s)
\]

\[
Y_3a_5=
\frac{a_1a_4^2Y_3}
     {a_1a_3-a_2^2}
+F(s)
\]

Multiplicando toda la ecuación por
\((a_1a_3-a_2^2)\):

\[
Y_3a_5(a_1a_3-a_2^2)
=
a_1a_4^2Y_3
+
(a_1a_3-a_2^2)F(s)
\]

Pasando los términos con \(Y_3\) al mismo lado:

\[
Y_3a_5(a_1a_3-a_2^2)
-
a_1a_4^2Y_3
=
(a_1a_3-a_2^2)F(s)
\]

Factorizando \(Y_3\):

\[
Y_3
\left[
a_5(a_1a_3-a_2^2)
-a_1a_4^2
\right]
=
(a_1a_3-a_2^2)F(s)
\]

Despejando:

\[
Y_3=
\frac{
(a_1a_3-a_2^2)
F(s)
}
{
a_5(a_1a_3-a_2^2)-a_1a_4^2
}
\]

Por lo tanto,

\[
\boxed{
\frac{Y_3(s)}{F(s)}
=
\frac{
a_1a_3-a_2^2
}
{
a_5(a_1a_3-a_2^2)-a_1a_4^2
}
}
\]

\subsection*{Paso 4. Función de transferencia de $m_2$}

Usando

\[
Y_2=
\frac{a_1a_4Y_3}
     {a_1a_3-a_2^2}
\]

sustituyendo \(Y_3/F\):

\[
\frac{Y_2(s)}{F(s)}
=
\frac{a_1a_4}
     {a_5(a_1a_3-a_2^2)-a_1a_4^2}
\]

\[
\boxed{
\frac{Y_2(s)}{F(s)}
=
\frac{a_1a_4}
     {a_5(a_1a_3-a_2^2)-a_1a_4^2}
}
\]

\subsection*{Paso 5. Función de transferencia de $m_1$}

Partiendo de

\[
Y_1=\frac{a_2}{a_1}Y_2
\]

sustituyendo \(Y_2/F\):

\[
Y_1=
\frac{a_2}{a_1}
\left(
\frac{a_1a_4}
     {a_5(a_1a_3-a_2^2)-a_1a_4^2}
\right)
F(s)
\]

Simplificando:

\[
\boxed{
\frac{Y_1(s)}{F(s)}
=
\frac{a_2a_4}
     {a_5(a_1a_3-a_2^2)-a_1a_4^2}
}
\]
